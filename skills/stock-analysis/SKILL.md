# 股票分析 Skill

## 目标

对用户指定的股票进行综合分析，帮助用户理解近期走势与可能的驱动因素。

## 工作流程

1. **识别股票**：从用户输入提取股票名称或 6 位代码；若只有名称，先用 stock_history 工具确认代码。
2. **查询历史行情**：调用 stock_history 工具，获取近期开盘价、收盘价、最高价、最低价、成交量。
3. **补充背景信息**（可选）：若用户关心"为什么涨/跌"，调用 web_search 工具搜索相关新闻与公告。
4. **分析**：结合价格走势与成交量变化，判断趋势（上涨/下跌/震荡）。
5. **输出**：用简洁中文给出结论，附关键数据支撑，不得编造未查询到的数字。

## 注意事项

- 所有行情数据必须来自 stock_history 工具返回结果，禁止编造。
- 实时消息必须来自 web_search，不要凭模型记忆猜测。
